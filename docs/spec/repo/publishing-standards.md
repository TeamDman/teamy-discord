# Publishing standards

This document defines the repository's local Tracey publishing requirements.

## Readme

repo[readme.explanation]
The repository README must explain what the project is and what problem it solves.

repo[readme.source-links]
The repository README must link to its source repository. Package links may be
included only when they identify an existing published package. Publication
badges are optional and must not imply an unverified package or release.

repo[readme.media-demo]
The repository README must include media showing the project's purpose or use,
such as an illustration, screenshot, video, or terminal recording.

repo[readme.code-example]
The repository README must include a command or code example demonstrating use.

## Repository basics

repo[license.present]
The repository must contain a license file.

repo[tracey.specification.present]
The repository must contain a local Tracey specification that can audit the project.

repo[implementation.present]
The repository must contain an implementation of the project it describes.

repo[description.meaningful]
The repository metadata and top-level documentation must describe the project.
